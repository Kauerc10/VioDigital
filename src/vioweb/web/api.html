API VioWeb para Sistemas de Cartório, Despachantes e Empresas

O uso do VioWeb no navegador é 100% gratuito para uso humano no balcão. Para empresas de software notarial, sistemas de despachantes, locadoras de veículos, seguradoras, fintechs e departamentos de onboarding que precisam automatizar a leitura e verificação de milhares de documentos em lote, oferecemos integração direta via API REST.

O que a API VioWeb entrega em uma única chamada?

  • Detecção Multi-QR de Alta Resolução: localiza e decodifica o QR Code VIO em PDFs (300 DPI) ou fotos mesmo quando há outros QR Codes na página (ex.: Selo Digital do TJ ou QR Code PIX).
  • Validação Criptográfica Oficial: verifica a assinatura digital ECDSA/RSA/ES512 contra a cadeia de certificados ICP-Brasil / SENATRAN / ONR.
  • Campos Padronizados e Formatados: Placa, RENAVAM, Chassi, CPF/CNPJ, Vendedor/Comprador da ATPV-e, Categoria CNH, TIE Marinha e +160 templates.
  • Extração da Fotografia Biométrica: retorna a foto oficial assinada pelo Serpro pronta para exibição e conferência facial.

Modalidades de Integração

  • Uso Manual Web (Balcão de Cartório): R$ 0 / sempre gratuito diretamente em vioweb.vercel.app.
  • API Cloud Gerenciada (B2B): Endpoint REST de alta disponibilidade com chave de API dedicada, rate-limit corporativo e suporte técnico para integração em ERPs.
  • Container On-Premise (Self-Hosted LGPD): Implantação isolada dentro da infraestrutura privada da sua empresa ou datacenter notarial, com zero tráfego externo.
